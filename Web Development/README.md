#  Code & Crumble

A simple and intuitive web platform focused on creating, managing, and sharing dessert recipes.

## Project Type
University group project completed as part of a Web Development course.

##  Features
- User sign-up and login system
- Create, update, and explore dessert recipes
- Daily featured recipe functionality
- Clean, responsive, and user-friendly design

##  Technologies Used
- Frontend: HTML, CSS, JavaScript, React
- Backend: PHP
- Database: MySQL

##  Notes
This project was developed through team collaboration.  
All team member information has been excluded to maintain privacy.
