# Cinema Management System

A database-driven system designed to manage and organize cinema information such as films, genres, directors, actors, cast details, and ratings.

---

##  Project Type
Academic group project developed as part of a Database course.

---

##  System Description
The Cinema Management System is designed to store and manage cinema-related data using a structured relational database.  
The project focuses on proper database design and data relationships.

---

##  Features
- Manage films with details such as title, language, and release date
- Genre management and film categorization
- Director management with one-to-many relationships
- Actor and cast management for films
- Movie ratings storage
- Structured relational database design
- UML Diagram, Chen ER Model, and Relational Schema

---

##  Technologies Used
- Database: MySQL
- Query Language: SQL
