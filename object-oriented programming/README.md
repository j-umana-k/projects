#  E-learning Platform

An object-oriented learning management system designed to simulate an online platform for courses and tutorials.

##  Project Type
Academic individual/group project developed as part of an Object-Oriented Programming (OOP) course.

##  Project Description
The E-learning Platform project focuses on applying core OOP principles through a structured system that represents users, courses, and platform operations.  
The system is built using multiple classes to model real-world roles and interactions within an online learning environment.

##  Features
- User management with different roles (Student, Professor, Admin)
- Course creation and management
- Student enrollment and course participation
- Professor course management and grading functionalities
- Admin control over users and courses
- Clear application of OOP concepts such as inheritance and polymorphism

##  OOP Concepts Applied
- Inheritance
- Polymorphism
- Encapsulation
- Exception Handling
- Collections
- Object Composition

##  Technologies Used
- Programming Language: Java
- Paradigm: Object-Oriented Programming (OOP)
